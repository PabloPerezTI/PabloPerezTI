# Profile SVG generator

The images in `../assets` are generated by `build.py` from the copy in `content.py`
(English and Spanish). Edit `content.py`, then rebuild:

```bash
cd tools
npm install @fontsource-variable/archivo @fontsource/fragment-mono
pip install fonttools brotli
python3 build.py ..
```

Fonts are subset to the characters each SVG uses and embedded as base64, so the
images look the same everywhere without loading anything external.
